## 🚀 Quick Start (5 Min Overview)

### Architecture in 30 Seconds
```
Users login via Email OTP or Google OAuth
    ↓
Django backend serves HTML & REST API
    ↓
WebSocket consumers handle real-time updates
    ↓
PostgreSQL stores all data
    ↓
Frontend updates live with no refresh needed
```

### Key Files
```
models.py          → Database schema (20+ models)
views.py           → Main logic (3000+ lines)
consumers.py       → WebSocket real-time
settings.py        → Configuration
urls.py            → Routes
```

### Core Models
```
User, Project, Comment, Message, Like
ProjectMember, Connection, Activity, Notification
```

### API Format
```
GET    /api/projects/
POST   /api/projects/
GET    /api/projects/<id>/
PUT    /api/projects/<id>/
DELETE /api/projects/<id>/
```
