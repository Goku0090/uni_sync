[ 1 ] Go to Google Cloud Console
      https://console.cloud.google.com/apis/credentials

[ 2 ] Click your OAuth 2.0 Client ID

[ 4 ] Click "Add URI"

[ 5 ] Paste exactly:
      http://127.0.0.1:8000/accounts/google/login/callback/

[ 6 ] Click "Save"

[ 7 ] Copy "Client ID" → Paste into .env as GOOGLE_CLIENT_ID

[ 8 ] Copy "Client Secret" → Paste into .env as GOOGLE_CLIENT_SECRET

[ 9 ] Go to GitHub Developer Settings
      https://github.com/settings/developers

[ 10] Click "OAuth Apps"

[ 11] Click your app

[ 12] Find "Authorization callback URL"

[ 13] Set to exactly:
      http://127.0.0.1:8000/accounts/github/login/callback/

[ 14] Click "Update application"

[ 15] Copy "Client ID" → Paste into .env as GITHUB_CLIENT_ID

[ 16] Copy "Client Secret" → Paste into .env as GITHUB_CLIENT_SECRET

[ 17] Update Django Admin site domain:
      Visit: http://127.0.0.1:8000/admin/sites/site/1/
      Change "Domain name" to: 127.0.0.1:8000
      Click "Save"

[ 18] Restart Django:
      python manage.py runserver

[ 19] Clear browser cookies:
      Press: Ctrl+Shift+Delete
      Clear All

[ 20] Test login:
      Go to: http://127.0.0.1:8000/accounts/login/
