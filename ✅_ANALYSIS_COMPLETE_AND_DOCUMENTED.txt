Step 2: Setup Local Environment (30 minutes)
  $ python -m venv venv
  $ source venv/bin/activate
  $ pip install -r requirements.txt
  $ python manage.py migrate
  $ python manage.py createsuperuser
  $ python manage.py runserver

Step 3: Explore the Code
  • Open accounts/models.py (understand data structure)
  • Open accounts/views.py (understand business logic)
  • Open accounts/urls.py (understand routing)
  • Open auth_project/settings.py (understand configuration)

Step 4: Test Features
  • Visit http://localhost:8000 (home page)
  • Visit http://localhost:8000/admin (admin panel)
  • Test signup with OTP
  • Explore project creation
  • Test messaging

Step 5: Start Developing
  • Choose a feature from FEATURE_BREAKDOWN_BY_FILE_2026.md
  • Understand its implementation
  • Make modifications as needed
  • Deploy to Render when ready

Core Models:
  User → StudentProfile (extended user data)
  Project (title, description, tech stack)
  Message (direct/group messaging)
  Connection (friend requests)
  Notification (alerts)
  Comment (on projects)
  Like (on projects)
  Activity (activity feed)

Key Views:
  register_view() → Email OTP signup
  login_view() → Email OTP login
  create_project_view() → Post new project
  project_feed() → Browse projects
  find_collaborators() → Smart matching
  chat_view() → Messaging

Important Files to Know:
  settings.py → Configuration (master file)
  models.py → Database structure (16 models)
  views.py → Business logic (50+ functions)
  urls.py → Routing (API + templates)
  serializers.py → API responses
  forms.py → Form validation

API Endpoints:
  POST /register/ → Create account with OTP
  POST /login/ → Login with OTP
  GET /api/projects/ → List projects
  POST /api/projects/ → Create project
  GET /api/messages/ → List messages
  POST /api/messages/ → Send message
  GET /api/notifications/ → User notifications

Configuration Files:
  .env → Environment variables
  requirements.txt → Python dependencies (80+)
  render.yaml → Deployment config
  Procfile → Production server config
