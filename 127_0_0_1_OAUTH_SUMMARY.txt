SOLUTION:

3 QUICK STEPS:

  [1] Add to Google Console
      https://console.cloud.google.com/apis/credentials
      → Click OAuth Client ID
      → Add redirect URI: http://127.0.0.1:8000/accounts/google/login/callback/
      → Save & copy credentials to .env

  [2] Add to GitHub Settings
      https://github.com/settings/developers
      → Click OAuth App
      → Set callback: http://127.0.0.1:8000/accounts/github/login/callback/
      → Update & copy credentials to .env

  [3] Restart Django
      python manage.py runserver
      → Clear browser cookies
      → Test login
