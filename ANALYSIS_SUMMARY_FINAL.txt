================================================================================
                         COMMON WORKFLOWS
================================================================================

WORKFLOW 1: Add a New Page
  1. Create template: accounts/templates/mypage.html
  2. Add view: def my_page(request): ... in views.py
  3. Add URL: path('my-page/', views.my_page, name='my_page') in urls.py
  4. Test in browser

WORKFLOW 2: Add API Endpoint
  1. Create serializer: class MySerializer(serializers.ModelSerializer): ...
  2. Create view: class MyAPIView(APIView): ...
  3. Add URL: path('api/my-endpoint/', MyAPIView.as_view(), name='my-api')
  4. Test with curl/Postman

WORKFLOW 3: Add Database Model
  1. Define: class MyModel(models.Model): ... in models.py
  2. Migrate: python manage.py makemigrations
  3. Apply: python manage.py migrate
  4. Create admin: admin.site.register(MyModel)

WORKFLOW 4: Send Email
  from django.core.mail import send_mail
  send_mail('Subject', 'Message', 'from@example.com', ['to@example.com'])

WORKFLOW 5: Debug Issue
  1. Check error logs: tail -f logs/django.log
  2. Use Django shell: python manage.py shell
  3. Look at similar working code
  4. Test with: python manage.py check
  5. Use IDE debugger or pdb.set_trace()
