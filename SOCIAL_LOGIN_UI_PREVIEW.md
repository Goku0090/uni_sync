## Animations

### Hover Animation
```
Duration:       300ms
Easing:         ease (smooth)
Transform:      translateY(-2px)
Effect:         Subtle lift effect
Subtle:         Professional, not distracting
```

### Magnetic Hover (JavaScript)
```
On mousemove:   Small translation based on cursor position
Effect:         Slight "magnetic" attraction to cursor
Smoothness:     Responsive but not jerky
On mouseleave:  Returns to normal position (200ms)
```

### Loading State
```
Duration:       Infinite
Icon:           FontAwesome spinner animation
Text:           Smooth color transition
Feedback:       Clear user indication
```
