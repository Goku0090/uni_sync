# Your URL is http://127.0.0.1:8000 - Fix for OAuth

## Your Situation

You're accessing your app at:
```
http://127.0.0.1:8000/
```

This is why you're getting the OAuth error!

---

## The Problem

You probably added these callback URLs to Google/GitHub:
```
❌ http://localhost:8000/accounts/google/login/callback/
❌ http://localhost:8000/accounts/github/login/callback/
```

But your app is at:
```
✅ http://127.0.0.1:8000/
```

**localhost** and **127.0.0.1** are different to OAuth providers!

---

## The Fix - 3 Actions

### Action 1: Update Google Settings

1. Go to: https://console.cloud.google.com/apis/credentials
2. Click your OAuth Client ID  
3. Add this redirect URI:
   ```
   http://127.0.0.1:8000/accounts/google/login/callback/
   ```
4. Click **Save**
5. Copy **Client ID** and **Client Secret** into your `.env` file

### Action 2: Update GitHub Settings

1. Go to: https://github.com/settings/developers
2. Click your OAuth App
3. Set Authorization callback URL to:
   ```
   http://127.0.0.1:8000/accounts/github/login/callback/
   ```
4. Click **Update application**
5. Copy **Client ID** and **Client Secret** into your `.env` file

### Action 3: Restart Django

```bash
python manage.py runserver
```

Clear your browser cookies (Ctrl+Shift+Delete) and test login again.

---

## Why This Matters

To OAuth providers:
- `localhost:8000` = localhost machine
- `127.0.0.1:8000` = 127.0.0.1 machine

Even though they're the same computer, OAuth treats them as different!

So you must add the **127.0.0.1** callback URLs to your OAuth settings.
