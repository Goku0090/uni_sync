## 💡 Key Technical Insights

### Architecture Pattern
```
Frontend (Templates/JS)
    ↓
Django Views (1000+ lines)
    ↓
Models (20+ database tables)
    ↓
PostgreSQL Database
    
Also:
REST APIs → Chat, Comments, Messaging
WebSocket → Real-time updates
Email → Brevo integration
OAuth → Google, GitHub
```

### Technology Stack
- **Backend**: Django 4.x + DRF
- **Frontend**: Bootstrap 5 + jQuery + Vanilla JS
- **Real-time**: Django Channels 4.0+
- **Database**: PostgreSQL (production) / SQLite (dev)
- **Email**: Brevo API (primary), ZeptoMail (fallback)
- **Auth**: Django Allauth + OTP via email
- **Deployment**: Render.com
- **Server**: Daphne (ASGI) for WebSocket

### Security Features
- CSRF token protection
- Session authentication
- Secure password hashing
- Email verification via OTP
- OAuth token management
- SQL injection protection (ORM)
- Secure headers configured
