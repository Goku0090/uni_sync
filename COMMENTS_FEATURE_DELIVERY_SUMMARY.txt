API ENDPOINTS

GET /accounts/api/projects/<project_id>/comments/
  Fetch all comments for a project
  Auth: Optional
  Response: JSON list of comments with user info

POST /accounts/api/projects/<project_id>/comments/add/
  Add new comment to project
  Auth: Required (login needed)
  Body: {"content": "Your comment here"}
  Response: New comment object

DELETE /accounts/api/comments/<comment_id>/delete/
  Delete a comment
  Auth: Required (own comment or project owner)
  Response: Success/Error message

PUT /accounts/api/comments/<comment_id>/edit/
  Edit a comment
  Auth: Required (own comment only)
  Body: {"content": "Updated comment"}
  Response: Updated comment object

API USAGE EXAMPLES

Get All Comments:
  curl http://localhost:8000/accounts/api/projects/1/comments/

Add Comment:
  curl -X POST http://localhost:8000/accounts/api/projects/1/comments/add/ \
    -H "Content-Type: application/json" \
    -H "X-CSRFToken: YOUR_TOKEN" \
    -d '{"content": "Great project!"}'

Delete Comment:
  curl -X DELETE http://localhost:8000/accounts/api/comments/5/delete/ \
    -H "X-CSRFToken: YOUR_TOKEN"

Edit Comment:
  curl -X PUT http://localhost:8000/accounts/api/comments/5/edit/ \
    -H "Content-Type: application/json" \
    -H "X-CSRFToken: YOUR_TOKEN" \
    -d '{"content": "Updated comment"}'

TROUBLESHOOTING

Problem: Comment section not appearing
Solution: Verify template include line is correct
         Clear browser cache (Ctrl+Shift+Del)
         Check template file exists in correct location

Problem: API returns 404 error
Solution: Verify urls.py has API imports
         Check route patterns match in urlpatterns
         Run python manage.py migrate

Problem: Comments not saving
Solution: Check database connection
         Run migrations
         Check Django logs for errors

Problem: CSRF token error
Solution: Ensure {% csrf_token %} in template
         Check MIDDLEWARE includes CSRF
         Verify CSRF_TRUSTED_ORIGINS in settings.py
