║                   OAUTH REDIRECT URI MISMATCH - CHEATSHEET                  ║
╚════════════════════════════════════════════════════════════════════════════╝

ERROR MESSAGE:
  Error 400: redirect_uri_mismatch
  "You can't sign in because this app sent an invalid request"

ROOT CAUSE:
  Callback URL in Django ≠ Callback URL in Google/GitHub

SOLUTION:
  Add correct callback URLs to Google & GitHub settings

════════════════════════════════════════════════════════════════════════════════

CALLBACK URLS (for localhost:8000):

  Google: http://localhost:8000/accounts/google/login/callback/
  GitHub: http://localhost:8000/accounts/github/login/callback/

  IMPORTANT:
    - Include the trailing slash /
    - Use http:// (not https://) for local dev
    - Include :8000 port number
    - Exactly as shown above

════════════════════════════════════════════════════════════════════════════════

QUICK FIX STEPS:

  [ 1 ] Go to Google Cloud Console
        https://console.cloud.google.com/apis/credentials
        
  [ 2 ] Click your OAuth 2.0 Client ID
  
  [ 3 ] Add redirect URIs:
        http://localhost:8000/accounts/google/login/callback/
        http://127.0.0.1:8000/accounts/google/login/callback/
        
  [ 4 ] Click Save
  
  [ 5 ] Copy Client ID → .env as GOOGLE_CLIENT_ID
  
  [ 6 ] Copy Client Secret → .env as GOOGLE_CLIENT_SECRET
  
  [ 7 ] Go to GitHub Settings
        https://github.com/settings/developers/oauth-apps
        
  [ 8 ] Click your OAuth App
  
  [ 9 ] Set Authorization callback URL:
        http://localhost:8000/accounts/github/login/callback/
        
  [ 10] Copy Client ID → .env as GITHUB_CLIENT_ID
  
  [ 11] Copy Client Secret → .env as GITHUB_CLIENT_SECRET
  
  [ 12] Restart Django:
         python manage.py runserver
  
  [ 13] Clear browser cookies (Ctrl+Shift+Delete)
  
  [ 14] Test login - should work now!

COMMON MISTAKES:

  ❌ /accounts/google/login/callback (MISSING SLASH)
  ✅ /accounts/google/login/callback/ (CORRECT)

  ❌ https://localhost:8000/... (WRONG FOR LOCAL)
  ✅ http://localhost:8000/... (CORRECT FOR LOCAL)

  ❌ http://localhost/... (MISSING PORT)
  ✅ http://localhost:8000/... (CORRECT WITH PORT)

  ❌ GOOGLE_CLIENT_ID= (EMPTY)
  ✅ GOOGLE_CLIENT_ID=123456789-abc... (FILLED)

  ❌ GoogleClientID (DIFFERENT NAME)
  ✅ GOOGLE_CLIENT_ID (EXACT NAME)
