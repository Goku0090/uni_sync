PERFORMANCE METRICS
================================================================================

Load Time Impact:
  - HTML:      +5 lines
  - CSS:       0 bytes (uses Tailwind utilities)
  - JavaScript: 0 bytes
  - Image:     1 logo.jpg (~20-50KB depending on optimization)

Rendering:
  - FCP (First Contentful Paint):  No impact
  - LCP (Largest Contentful Paint): ~50-100ms (logo image)
  - CLS (Cumulative Layout Shift):  0 (fixed layout)

Optimization Tips:
  1. Use WebP format for logo (saves 50-70% size)
  2. Optimize JPG/PNG (use TinyPNG or similar)
  3. Add width/height attributes to img (prevents layout shift)
  4. Use loading="lazy" for images below fold

Optimized HTML:
  <img src="{% static 'images/logo.jpg' %}"
       alt="UniSync Logo"
       width="56"
       height="56"
       loading="lazy"
       class="...">
