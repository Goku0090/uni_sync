================================================================================
GOOGLE LOGIN - REDIRECT URI MISMATCH ERROR
================================================================================

ERROR MESSAGE:
  Error: redirect_uri_mismatch
  The redirect URI provided does not match the one registered with the 
  authorization server

ROOT CAUSE:
  Your app is trying to use a callback URL that Google doesn't recognize

SOLUTION:
  Register the callback URL in Google Cloud Console

================================================================================
QUICK FIX (5 MINUTES)
================================================================================

1. FIND YOUR CALLBACK URL
   For localhost:
   http://localhost:8000/accounts/google/login/callback/
   
   For production:
   https://yourdomain.com/accounts/google/login/callback/

2. ADD TO GOOGLE CLOUD CONSOLE
   Go to: console.cloud.google.com
   - Select your project
   - APIs & Services → Credentials
   - Click your OAuth 2.0 Client ID
   - Scroll to "Authorized redirect URIs"
   - Click "ADD URI"
   - Paste your callback URL
   - Click "SAVE"

3. UPDATE .env FILE
   GOOGLE_CLIENT_ID=your_client_id_from_google
   GOOGLE_CLIENT_SECRET=your_client_secret_from_google
   ALLOWED_HOSTS=localhost,127.0.0.1

4. RESTART SERVER
   python manage.py runserver

5. TEST
   Visit: http://localhost:8000/accounts/login/
   Click: Login with Google
   Should work! ✅

================================================================================
COMMON MISTAKES
================================================================================

❌ Using 127.0.0.1 but registered localhost
   Fix: Add both to Google Console

❌ Using port 8001 but registered 8000
   Fix: Use exact port in Google Console

❌ Missing trailing slash in callback URL
   Fix: Callback MUST be: .../callback/ (with slash)

❌ Typo in Client ID or Secret
   Fix: Copy-paste directly from Google Console

❌ Registered but didn't click SAVE
   Fix: Always click SAVE button in Google Console

❌ Server not restarted
   Fix: Restart Django after changing .env

❌ Browser cache not cleared
   Fix: Clear cache (Ctrl+Shift+Delete)
