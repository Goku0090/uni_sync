# Google OAuth Setup Guide - Complete Reference

## How Google OAuth Works

```
1. User clicks "Login with Google"
         ↓
2. Browser redirects to: 
   https://accounts.google.com/o/oauth2/v2/auth?...
         ↓
3. User logs in with Google account
         ↓
4. User grants permission
         ↓
5. Google redirects back to:
   YOUR_APP_URL/accounts/google/login/callback/
         ↓
6. Your app processes the callback
         ↓
7. User is logged in to your app
```

**The Problem**: If step 5's URL doesn't match what you registered, you get the error.

## Setup Checklist

### 1. Google Cloud Console Setup

- [ ] Create/open Google Cloud project
- [ ] Enable Google+ API
- [ ] Create OAuth 2.0 Credentials (Web Client)
- [ ] Copy Client ID and Client Secret
- [ ] **Add Authorized Redirect URI**:
  ```
  http://localhost:8000/accounts/google/login/callback/
  ```
- [ ] Click SAVE

### 2. Django Settings

- [ ] Install django-allauth: `pip install django-allauth`
- [ ] Add to INSTALLED_APPS:
  ```python
  'allauth',
  'allauth.account',
  'allauth.socialaccount',
  'allauth.socialaccount.providers.google',
  ```
- [ ] Add middleware:
  ```python
  'allauth.account.middleware.AccountMiddleware',
  ```
- [ ] Add SOCIALACCOUNT_PROVIDERS (already in your code ✓)

### 3. Environment Variables

- [ ] Update `.env` file:
  ```
  GOOGLE_CLIENT_ID=your_client_id
  GOOGLE_CLIENT_SECRET=your_client_secret
  ALLOWED_HOSTS=localhost,127.0.0.1
  ```

### 4. Database

- [ ] Run migrations:
  ```bash
  python manage.py migrate
  ```

### 5. Test

- [ ] Start server
- [ ] Visit login page
- [ ] Click "Login with Google"
- [ ] Verify it works

## Finding Your Credentials

### Step 1: Go to Google Cloud Console

```
https://console.cloud.google.com/
```

### Step 2: Select Your Project

![](select-project.png)
- Click the project dropdown at the top
- Select your project (or create a new one)

### Step 3: Enable Google+ API

- Go to **APIs & Services** (left sidebar)
- Click **Library**
- Search for "Google+ API"
- Click it
- Click **ENABLE**

### Step 4: Create Credentials

- Go to **APIs & Services** → **Credentials** (left sidebar)
- Click **Create Credentials**
- Select **OAuth Client ID**
- Choose **Web Application**
- Fill in:
  - **Name**: UniSync OAuth
  - **Authorized JavaScript origins**: Add your domain
  - **Authorized redirect URIs**: 
    ```
    http://localhost:8000/accounts/google/login/callback/
    ```
- Click **Create**

### Step 5: Copy Credentials

- You'll see a popup with your credentials
- Copy:
  - **Client ID**
  - **Client Secret**
- Paste into `.env`:
  ```
  GOOGLE_CLIENT_ID=your_copied_client_id
  GOOGLE_CLIENT_SECRET=your_copied_client_secret
  ```

## Callback URL Explained

Your app uses this callback URL pattern:

```
http://localhost:8000/accounts/google/login/callback/
```

Breaking it down:
- `http://` - Protocol (http for localhost, https for production)
- `localhost` - Your domain (or your actual domain)
- `:8000` - Port (8000 is Django default, might be different)
- `/accounts/google/login/callback/` - Fixed path (django-allauth default)

**This path is auto-generated by django-allauth**, you can't change it.

You must register this exact URL in Google Cloud Console.

## Troubleshooting Guide

### Error: "Invalid client_id"

**Cause**: Client ID in .env doesn't match Google Cloud Console

**Fix**:
1. Go to Google Cloud Console
2. Copy Client ID
3. Paste into .env as GOOGLE_CLIENT_ID
4. Make sure there are no extra spaces
5. Restart server

---

### Error: "Invalid client secret"

**Cause**: Client Secret in .env doesn't match Google Cloud Console

**Fix**:
1. Go to Google Cloud Console
2. Click your OAuth Client ID
3. Copy the Client Secret
4. Paste into .env as GOOGLE_CLIENT_SECRET
5. Restart server

---

### Error: "redirect_uri_mismatch"

**Cause**: Callback URL doesn't match

**Fix**:
1. Get your callback URL:
   - For localhost: `http://localhost:8000/accounts/google/login/callback/`
   - For production: `https://yourdomain.com/accounts/google/login/callback/`
2. Go to Google Cloud Console
3. Click your OAuth Client ID
4. Find "Authorized redirect URIs"
5. Click "ADD URI"
6. Paste your callback URL
7. Click "SAVE"
8. Restart Django server
9. Clear browser cache
10. Try again

---

### Error: "The authorization server does not support obtaining a refresh token for this user"

**Cause**: Google settings require specific scopes

**Fix** (already in your code):
```python
SOCIALACCOUNT_PROVIDERS = {
    'google': {
        'SCOPE': ['profile', 'email'],
        'AUTH_PARAMS': {'access_type': 'online'},  # ← This line
    }
}
```

This is already correct in your settings.py ✓

---

### Google Login Button Not Appearing

**Cause**: Missing django-allauth template

**Check**: You have the login template and include google button:
```html
{% load socialaccount %}
<a href="{% provider_login_url 'google' %}">Login with Google</a>
```

**If missing**: Add to your login template

---

### After Login, Redirect Loop

**Cause**: LOGIN_REDIRECT_URL not configured properly

**Fix** (already in your code):
```python
LOGIN_REDIRECT_URL = '/dashboard/'
```

Make sure `/dashboard/` route exists.

## After Login User Creation

When user logs in via Google:
1. Django-allauth checks if user exists
2. If not, creates new user automatically
3. Links Google account to user
4. Creates entry in SocialAccount table

**Check database**:
```bash
python manage.py shell
>>> from django.contrib.auth.models import User
>>> User.objects.all()  # Should show new user from Google
```

## OAuth Scope Explanation

Your app requests:
```python
'SCOPE': ['profile', 'email']
```

This means:
- **profile**: Access to name, picture, birthday, etc.
- **email**: Access to email address

These are the minimal scopes needed. You can add more if needed:
```python
'SCOPE': ['profile', 'email', 'https://www.googleapis.com/auth/calendar']
```
