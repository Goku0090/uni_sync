   python manage.py create_templates

3. Add Navigation Link
   <a href="{% url 'templates_list' %}">📋 Templates</a>

USER FLOW:

1. User visits /templates/
2. Browses 10 featured templates with icons
3. Clicks on a template to see details
4. Sees:
   - Description
   - Technologies
   - Required roles
   - Timeline and team size
   - Learning resources
   - User rating
5. Clicks "Use This Template"
6. Form pre-fills with all template data:
   - Title
   - Description
   - Technologies
   - Roles needed
   - Category
   - Timeline
7. Customizes fields as needed
8. Submits to create project
9. Project created instantly
10. Usage automatically logged

RATING FLOW:

1. User visits template detail page
2. Sees average rating and review count
3. Clicks star rating (1-5 stars)
4. Optionally writes review
5. Submits rating
6. Template average updated
7. User can edit rating anytime

================================================================================
DATABASE STRUCTURE
================================================================================

ProjectTemplate (Main table)
├── name (unique)
├── category (web, mobile, ai, data, blockchain, iot, game)
├── description
├── icon (emoji)
├── template_title (pre-filled)
├── template_description (pre-filled)
├── template_technologies (JSON array)
├── template_looking_for (JSON array)
├── suggested_timeline
├── suggested_team_size
├── difficulty_level
├── example_projects (links)
├── learning_resources (links)
├── rating (0-5.0 average)
├── rating_count
├── usage_count
├── is_active
├── is_featured
└── timestamps

TemplateRating (Ratings table)
├── template (FK)
├── user (FK)
├── rating (1-5)
├── review (optional)
├── helpful_count
├── unique: (template, user)
└── timestamps

TemplateUsageLog (Usage tracking)
├── template (FK)
├── user (FK)
├── project (FK, optional)
└── created_at

================================================================================
API ENDPOINTS
================================================================================

WEB PAGES:
  GET  /templates/                      List all templates
  GET  /templates/<id>/                 View template details
  GET  /templates/<id>/use/              Use template form
  POST /templates/<id>/rate/             Rate template (AJAX)
  GET  /templates/<id>/my-rating/        Get user rating

REST API:
  GET  /api/templates/                  List templates (JSON)
       Parameters: category, difficulty, search
  
  GET  /api/templates/<id>/             Get template (JSON)
  
  POST /api/templates/<id>/create-project/  Create project from API
       Body: {title, description, technologies, looking_for}
  
  POST /api/templates/<id>/rate/        Rate template (JSON)
       Body: {rating (1-5), review (optional)}
