## 📞 Quick Help Reference

### Issue Troubleshooting

**Templates don't show on GitHub:**
- Verify `.github/ISSUE_TEMPLATE/` directory exists
- Ensure files end with `.md`
- Wait 5 minutes for cache clear
- Try creating new issue

**Workflows don't run:**
- Check `.github/workflows/` exists
- Verify YAML syntax (use yaml validator)
- Check Actions tab on GitHub
- Enable workflows if disabled

**README doesn't render:**
- Verify markdown syntax
- Check special characters
- Test locally with markdown viewer
- Look for encoding issues
