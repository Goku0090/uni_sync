## 🐛 Something Wrong?

### Problem: Template not showing
```bash
python manage.py collectstatic
```

### Problem: Colors not loading
Press `Ctrl+Shift+R` to hard refresh browser cache

### Problem: Mobile not responsive
Check if viewport meta tag is in base template

### Problem: Buttons not working
Check if CSRF token is present in form

See [QUICK_START.md Troubleshooting](./QUICK_START_FIND_COLLABORATORS.md) for more help.
