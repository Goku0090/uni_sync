🚀 QUICK START (5 MINUTES)
===============================================================================
1. Create static directories
   mkdir -p auth_project/accounts/static/{css,js}

2. Copy files
   cp messages.css → static/css/
   cp messages-*.js → static/js/
   cp messages_improved.html → templates/features/messages.html

3. Collect static files
   python manage.py collectstatic --noinput

4. Run server
   python manage.py runserver

5. Test
   http://localhost:8000/accounts/messages/

🔌 REQUIRED API ENDPOINTS
===============================================================================
Your backend MUST provide:

GET  /api/messages/              List conversations
GET  /api/messages/{id}/         Get messages in conversation
POST /api/messages/              Send message
POST /api/messages/{id}/read/    Mark message as read

GET  /api/messages/search/       Search messages
POST /api/messages/{id}/react/   Add reaction

GET  /api/chat-rooms/            List group chats
POST /api/chat-rooms/            Create group chat
POST /api/chat-rooms/{id}/members/  Add member

See existing chat_api.py for implementation reference.

===============================================================================

  - Token extracted from cookie/meta tag
  - Included in all POST/PUT/DELETE requests
  - Server-side validation required

✓ XSS Prevention
  - No innerHTML with user input
  - Template literals use .textContent
  - User content properly escaped

✓ Input Validation

✓ Error Handling
