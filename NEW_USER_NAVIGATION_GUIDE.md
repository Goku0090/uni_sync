## Open UniSinq

- Open your browser and go to the app URL, for example:
  - `http://127.0.0.1:8000/`
- This should show the UniSinq homepage with the navigation menu, login button, and feature sections.

## Login or Sign Up

- Click the `Login` button in the top navigation bar or visit:
  - `/login/`
- If you already have an account, enter your credentials and sign in.
- If you are a new user, use the registration option to create an account.
- Once logged in, the site should change the menu to show your profile and other member-only pages.

## Homepage / Main Feed

- After login, you will land on the main feed page or homepage.
- The main feed displays:
  - recent projects
  - trending posts
  - recommended collaborators
- Use the navigation menu to move between pages like `Main Home`, `Profile`, and `Find Collaborators`.
- Look for buttons or cards that let you explore projects and discover active teams.

## Post a New Project

- Navigate to the project posting page using the `Post a Project` page or a similar button.
- Fill out all required fields, including:
  - Project title
  - Short description
  - Detailed description
  - Project category or required skills
  - Collaboration needs
- Make the detailed description clear: explain the problem, your solution, the tech stack, and what help you need.
- Submit the form and check for any validation prompts if required fields are missing.
- A properly submitted project should appear in the live feed or latest projects section.

## Find Collaborators

- Use the `Find Collaborators` feature to browse student profiles and teammate suggestions.
- You can search for people based on:
  - skills
  - interests
  - study areas
  - availability
- Review each profile card and look for matching teammates.
- Send a connection request when you find someone whose skills fit your project.
- If a profile is already connected, look for a chat or join button to start a conversation.

## Chat with Teammates

- Once you have accepted or invited teammates, use the chat page to communicate.
- Open chat from the profile, connections page, or direct project chat link.
- Use chat for:
  - discussing project goals
  - sharing files and links
  - planning design and development tasks
- Keep communication concise and focused to move the project forward.

## Edit Your Profile

- Visit your profile page, usually at:
  - `/student-profile/`
- Complete or update important fields such as:
  - full name
  - profile photo
  - bio
  - skills and interests
  - college, location, and project preferences
- A complete profile helps collaborators understand your experience and what you offer.
- Save changes after updating any fields.

## Use Notifications and Activity

- Watch for in-app notifications about:
  - new collaboration requests
  - project comments
  - team messages
  - project updates
- Notifications help you respond quickly and stay active on your projects.
- If your app has an activity feed, check it regularly for team activity and project progress.

## Tips for Success

- Keep your project description clear and easy to understand.
- Add details about what stage your project is in and the skills you need.
- Engage with teammates and reply promptly in chat.
- Update your profile often as your skills or availability change.
- Use the site navigation to quickly jump to `Home`, `Profile`, `Projects`, and `Collaborators`.

### Quick Navigation Summary

- `Home` or `Main Feed`: discover projects and activity.
- `/login/`: login page.
- `Post a Project`: create a new listing.
- `Find Collaborators`: browse and connect with teammates.
- `Profile` or `/student-profile/`: edit your personal details.
- `Chat`: message your project team.
