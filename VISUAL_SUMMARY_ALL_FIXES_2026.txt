SCENARIO: User clicks template in /post-project/ form

BEFORE ❌
────────────────────────────────────────────────────────────────────────────────
1. User clicks template card
2. JavaScript calls: fetch('/api/templates/5/')
3. URL matches: /templates/<id>/ web view (wrong pattern)
4. View requires login (@login_required) → 403 Forbidden
5. Response is HTML error page
6. JavaScript tries JSON.parse(html) → SyntaxError
7. User sees: "Could not auto-fill template details: SyntaxError..."

9. User has to type everything manually

AFTER ✅
────────────────────────────────────────────────────────────────────────────────
1. User clicks template card
2. JavaScript calls: fetch('/api/template/5/json/')
3. URL matches: /api/template/<id>/json/ API view (correct pattern)
4. View returns JSON with all template data
5. Response is valid JSON
6. JavaScript parses successfully
7. Form auto-fills with template data
8. User sees: "Template auto-filled!" ✅
9. User can click submit to create project
10. Form is pre-filled, saving time
