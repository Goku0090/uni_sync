## Learning Path

### For New Backend Developer
1. Read PROJECT_SUMMARY.md + ARCHITECTURE.md (1-2 hours)
2. Follow SETUP_AND_DEPENDENCIES.md to get running (1 hour)
3. Explore: models.py → views.py → urls.py (2 hours)
4. Use QUICK_REFERENCE.md for daily tasks
5. Start implementing features

### For New Frontend Developer
