================================================================================
WHY THIS WORKS
================================================================================

Message model structure:
✅ message.mark_as_read_by(user)  → Marks as read
✅ message.is_read_by(user)       → Checks if read

Instead of:
❌ is_read=False    → Doesn't exist!

MessageReadStatus table:
  message_id | user_id | read_at
  -----------|---------|----------
       1     |    2    | 2024-01-28...

When a user reads a message, an entry is created in MessageReadStatus.
