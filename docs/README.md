# UniSinq Documentation

This directory contains all project documentation organized by category.

## Directory Structure

### 📚 `/api/`

- API endpoints reference
- Request/response examples
- Authentication guides

### 🚀 `/deployment/`
Deployment guides, checklists, and infrastructure documentation
- Render deployment guides
- Docker configuration
- Environment setup
- CI/CD pipelines

### ✨ `/features/`
Feature documentation and implementation guides
- User stories and requirements
- Feature specifications
- Implementation details
- User guides

### 🔧 `/troubleshooting/`
Bug fixes, error resolution, and debugging guides
- Common issues and solutions
- Error troubleshooting
- Debug procedures
- Fix summaries

### 🏗️ `/architecture/`
System architecture and technical documentation
- System design documents
- Database schemas
- Component diagrams
- Technical specifications

## Contributing to Documentation

When adding new documentation:
1. Choose the appropriate category folder
2. Use descriptive filenames with dates if version-specific
3. Update this README if adding new categories
4. Keep documentation current with code changes
