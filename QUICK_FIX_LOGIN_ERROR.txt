PROBLEM
═══════════════════════════════════════════════════════════════════════════════════

❌ Error when visiting: http://127.0.0.1:8000/login/

Error Message:
  MultipleObjectsReturned at /login/
  No exception message supplied

Root Cause:
  You have MULTIPLE OAuth apps configured for the same provider
  (Google or GitHub appears 2+ times in database)

│ ├─ GitHub App #1     │  ← Duplicate!

└──────────────────────┘

After (Fixed):
┌──────────────────────┐

     ✅ Works perfectly!


WHY DID THIS HAPPEN?
═══════════════════════════════════════════════════════════════════════════════════

You probably ran OAuth setup scripts multiple times:

  1. First run → Created Google & GitHub apps ✅
  2. Second run → Created DUPLICATE Google & GitHub apps ❌
  3. Django gets confused → Error!
