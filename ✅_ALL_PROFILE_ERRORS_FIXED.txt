ERROR #1: PROJECT FIELD ERROR
═════════════════════════════════════════════════════════════════════════════

The Error:
  django.core.exceptions.FieldError: Cannot resolve keyword 'visibility' into field
  
Location:
  File: accounts/views.py
  Line: 2655
  Function: user_profile()
  
Full Error Message:
  Cannot resolve keyword 'visibility' into field. Choices are: activity, category, 
  chat_rooms, collaboration_needs, comments, created_at, description, github_link, 
  id, invitations, is_active, likes, looking_for, members, milestones, tasks, 
  technologies, timeline, title, updated_at, user, user_id

Problem:
  The code tried to filter Project objects using a 'visibility' field:
  
  projects = Project.objects.filter(
      user=profile_user,
      visibility__in=['public', 'shared']  # ❌ This field doesn't exist!
  )
  
  But the Project model doesn't have a 'visibility' field.

Root Cause:
  • Incorrect field name used in filter
  • Project model uses 'is_active' boolean, not visibility
  • Django threw FieldError with helpful list of actual fields

Solution:
  Changed the filter to use the correct field that exists:
  
  projects = Project.objects.filter(
      user=profile_user,
      is_active=True  # ✅ This field exists!
  )

ERROR #2: TEMPLATE SYNTAX ERROR
═════════════════════════════════════════════════════════════════════════════

The Error:
  django.template.exceptions.TemplateSyntaxError: 'for' statements should use 
  the format 'for x in y': for interest in student_profile.interests.split ','
  
Location:
  File: templates/social/user_profile.html
  Line: 251
  
Problem:
  The template tried to use invalid Django template syntax:
  
  {% for interest in student_profile.interests.split ',' %}
  ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  This syntax is wrong - Django doesn't support method calls in for loops
  
Root Cause:
  • Incorrect template syntax for filters
  • Django uses pipe syntax for filters, not method calls
  • Missing filter argument quotes
  
Solution:
  Changed to correct Django template filter syntax:
  
  {% if student_profile.interests %}
      {% for interest in student_profile.interests|split:"," %}
      ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
      Correct: pipe + filter name + colon + quoted argument
          ...
      {% endfor %}
  {% endif %}

TEMPLATE SYNTAX RULES
═════════════════════════════════════════════════════════════════════════════

Django Template Filters - Correct Syntax:

✅ CORRECT:
  {{ variable|filter }}
  {{ variable|filter:"argument" }}
  {{ variable|filter:"arg1":"arg2" }}
  
Examples:
  {{ text|lower }}
  {{ string|split:"," }}
  {{ value|add:"10" }}

❌ WRONG:
  {{ variable.method() }}
  {{ variable|method ',' }}
  {% for x in variable.method ',' %}
  
These are NOT template syntax:
  .method() - not allowed in templates
  'quoted' - use double quotes in filters
  space-separated args - use colons
