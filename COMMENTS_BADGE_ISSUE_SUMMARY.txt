COMMENTS BADGE BUG - ISSUE & SOLUTION SUMMARY
═════════════════════════════════════════════════════════════════════

ISSUE REPORTED
───────────────────────────────────────────────────────────────────
"The comments badge shows 0, when clicked on comment then it updates 
and shows the comments"

LOCATION
───────────────────────────────────────────────────────────────────
File: accounts/templates/social/activity_feed.html
  • Line 634: Comment badge display
  • Line 691: Comment count in header  
  • Lines 1029-1044: handleCommentClick() function

ROOT CAUSE
───────────────────────────────────────────────────────────────────
1. Comment count badge is hardcoded to "0"
2. handleCommentClick() only toggles visibility
3. Comments are fetched only when needed (lazy loading)
4. Badge count never updated when comments are loaded

BEHAVIOR
───────────────────────────────────────────────────────────────────
BEFORE FIX:
  • Initial state: Badge shows "0" (hardcoded)
  • After click: Comments load somewhere
  • Then: Badge updates to correct count

AFTER FIX:
  • Initial state: Badge shows actual count
  • After click: Comments load immediately
  • Badge stays updated

WHY THIS HAPPENS
───────────────────────────────────────────────────────────────────
The JavaScript function that handles clicking only:
  - Toggles the visibility of comments section
  - Does NOT call API to fetch comments
  - Does NOT update badge count

When user clicks, the section becomes visible, and at some point 
comments load (possibly another script), then badge updates.

SOLUTION
───────────────────────────────────────────────────────────────────
Make handleCommentClick() actively load comments and update badge
when section is opened.

3 Simple Changes:
  1. Add data-project-id to activity card
  2. Add ID to comment badge element
  3. Replace handleCommentClick() with version that:
     - Fetches comments from API
     - Updates badge count
     - Renders comments in section
