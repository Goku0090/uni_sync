═══════════════════════════════════════════════════════════════════════════════
                          IF SOMETHING'S WRONG
═══════════════════════════════════════════════════════════════════════════════

Check the console error message:

1. "Unexpected token '<'" or "<!DOCTYPE"
   → HTML is being returned instead of JSON
   → Need to check why pure Django endpoint isn't working
   → Run: python manage.py showurls | grep template

2. "404 Not Found"
   → Endpoint URL doesn't match
   → Verify URL: /api/template/{id}/json/
   → Check if template ID exists in database

3. "TypeError: Cannot read property..."
   → Form field IDs don't match
   → Check fillFormFromTemplate() function
   → Verify form field names are correct

4. "All template endpoints failed"
   → Both endpoints returning errors
   → Server might need restart
   → Try: Ctrl+C and python manage.py runserver
