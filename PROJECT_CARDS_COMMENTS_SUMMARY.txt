================================================================================
API INTEGRATION
================================================================================

ENDPOINTS USED (all existing):

1. GET /api/projects/{project_id}/comments/
   └─ Fetches all comments for a project
   └─ Returns: comments list, count, permissions

2. POST /api/projects/{project_id}/comments/add/
   └─ Adds new comment
   └─ Body: { "content": "comment text" }
   └─ Returns: created comment with ID

3. DELETE /api/comments/{comment_id}/delete/
   └─ Deletes a comment
   └─ Returns: success message

4. POST /api/comments/{comment_id}/edit/
   └─ Updates comment content
   └─ Body: { "content": "updated text" }
   └─ Returns: updated comment
