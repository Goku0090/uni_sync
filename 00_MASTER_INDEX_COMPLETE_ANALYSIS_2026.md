## 💡 Key Insights

### Technology Stack
```
Backend: Django 4.x + Django REST Framework
Frontend: Bootstrap 5 + jQuery + Vanilla JS
Real-time: Django Channels + WebSocket
Database: PostgreSQL (Render) / SQLite (Dev)
Email: Brevo API (Primary)
Auth: Django Allauth + OTP
Deployment: Render.com
```

### Architecture Pattern
```
Frontend (Templates/JS) → Django Views → Models → Database
                              ↓
                           REST APIs
                              ↓
                        Chat API / Comment API
                              ↓
                        WebSocket / Signals
                              ↓
                        Real-time Updates
```

### Data Flow
```
User Input → Form/AJAX → View → Model → Database
Database → Signal → WebSocket → Client JS → DOM Update
```
