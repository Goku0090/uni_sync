HOW IT WORKS:
=============
1. Page loads → Django renders project_detail.html
2. Includes comment_section.html (safe HTML/CSS only)
3. JavaScript handler loads from /static/js/comments-handler.js
4. JavaScript finds comment section element
5. Loads comments via AJAX GET request
6. Comments display on page
7. User interactions trigger AJAX POST/PUT/DELETE
8. Comments refresh automatically

TROUBLESHOOTING:
================
If comments not showing:
  → Hard refresh: Ctrl+Shift+R
  → Clear cache: python manage.py clear_cache
  → Restart: python manage.py runserver

If JavaScript errors:
  → Check console: F12 → Console tab
  → Check script loaded: F12 → Network tab
  → Look for comments-handler.js status 200

If can't post comment:
  → Make sure logged in
  → Check CSRF token present
  → Check network tab for API errors
  → Check Django logs
