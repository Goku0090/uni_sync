📋 REQUIREMENTS:
  • Python 3.11+ (already installed)
  • Node.js 18+ (download from nodejs.org if needed)

═══════════════════════════════════════════════════════════════════

🚀 STEP 1: Start Backend (Terminal 1)
──────────────────────────────────────

cd e:\login\backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver

You should see:
  ✓ Starting development server at http://127.0.0.1:8000/

Keep this terminal open!


🚀 STEP 2: Start Frontend (Terminal 2 - NEW)
──────────────────────────────────────────────

Open NEW PowerShell window

cd e:\login\frontend

npm install

npm run dev

You should see:
  ✓ VITE v5.0.0  ready in XXX ms
  ✓ Local:   http://localhost:5173/

Keep this terminal open!


═══════════════════════════════════════════════════════════════════

🌐 ACCESS YOUR APPLICATION:

Frontend:   http://localhost:5173  ✅
Backend:    http://localhost:8000  ✅
Admin:      http://localhost:8000/admin  ✅

═══════════════════════════════════════════════════════════════════

⚙️ IF npm install FAILS:

Try this:
  npm install --legacy-peer-deps

Or install Node.js first:
  Download from nodejs.org

═══════════════════════════════════════════════════════════════════

⚙️ IF python manage.py runserver FAILS:

Install missing packages:
  pip install -r requirements.txt

Or if specific package fails:
  pip install textblob nltk spacy scikit-learn

═══════════════════════════════════════════════════════════════════

✅ NEXT STEPS:

1. Open TWO terminals
2. Run Step 1 in Terminal 1 (Backend)
3. Run Step 2 in Terminal 2 (Frontend)
4. Visit http://localhost:5173

═══════════════════════════════════════════════════════════════════

🛑 TROUBLESHOOTING:

"venv command not found"
→ Use: python -m venv venv

"npm command not found"
→ Install Node.js from nodejs.org

"Port 8000 already in use"
→ Kill it: taskkill /PID <PID> /F
→ Or use different port: python manage.py runserver 8001

"ModuleNotFoundError"
→ Activate venv first: venv\Scripts\activate
→ Then install: pip install -r requirements.txt
