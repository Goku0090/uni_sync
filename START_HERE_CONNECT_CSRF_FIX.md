# START HERE: Connect Button 403 Forbidden Fix

## What Happened?
When users clicked the **"Connect"** button on collaborator cards in the Find Collaborators page, they got a **403 Forbidden** error instead of sending a connection request.

**Error:** `POST http://127.0.0.1:8000/connect/3/ 403 (Forbidden)`

## What Was Broken?
The `find_collaborators_enhanced.html` template was missing the CSRF token, which Django requires for all POST requests.

## What's Fixed?
✅ Added the CSRF token to the template  
✅ Connect button now works without errors  
✅ Users can send connection requests successfully  

---

## The Fix (1 Line)

**File:** `find_collaborators_enhanced.html`

**Add this line before the `<script>` section:**
```html
{% csrf_token %}
```

**That's it!**

## The Technical Explanation

### What Django Requires
Django has CSRF (Cross-Site Request Forgery) protection that requires a token for all POST requests. The token is generated by:

```html
{% csrf_token %}
```

This creates:
```html
<input type="hidden" name="csrfmiddlewaretoken" value="abc123xyz789...">
```

### What the JavaScript Does
The `connectWith()` function looks for this token:

```javascript
const csrf = document.querySelector('[name=csrfmiddlewaretoken]');
if (csrf) form.appendChild(csrf.cloneNode());
```

**Before fix:** Token not found → ❌  
**After fix:** Token found → ✅
