                        WHAT WAS THE PROBLEM
================================================================================

Symptom:
  - Logo displays as broken image icon
  - Appears on all pages
  - No obvious errors in console

Root Cause Found:
  File: project_detail.html
  Line: 29
  Issue: Used hardcoded path instead of Django template tag
  
  Code:
    <img src="/static/images/unisync_logo.jpg" ...>  ❌ WRONG
    
  Should be:
    <img src="{% static 'images/logo.jpg' %}" ...>  ✅ CORRECT

Why It Failed:
  • Hardcoded paths don't resolve correctly in templates
  • Django needs to process path through {% static %} tag
  • Breaks with collectstatic and on production

================================================================================
                    BEST PRACTICES
================================================================================

Always Use:
  ✅ {% static 'path/to/file' %}       (Correct)
  ✅ {% load static %} at top           (Required)

Never Use:
  ❌ /static/path/to/file              (Hardcoded)
  ❌ ../static/...                     (Relative)
  ❌ file:///C:/path/...               (File system)

Why:
  • Django processes static tags
  • Works with collectstatic
  • Works with CDN
  • Works across environments (dev, staging, prod)

================================================================================
                    DJANGO STATIC FILES
================================================================================

Configuration in settings.py:
  STATIC_URL = '/static/'
  STATIC_ROOT = 'staticfiles'
  STATICFILES_DIRS = ['static']

Development Flow:
  1. Files in: auth_project/static/
  2. Accessed via: {% static 'path/to/file' %}
  3. URL: /static/path/to/file
  4. Served by: Django runserver

Production Flow:
  1. Run: python manage.py collectstatic
  2. Files copied to: staticfiles/
  3. Served by: Web server (nginx) or CDN
  4. Django: Just references via {% static %}

Template Tag:
  {% load static %}
  <img src="{% static 'images/logo.jpg' %}">
  
  Output:
  <img src="/static/images/logo.jpg">
