PROBLEM:
--------
When one user posts a comment on a project, other users cannot see it.

ROOT CAUSE:
-----------
Duplicate 'api/' prefix in URL routes for comments:
  - Routes defined as: path('api/projects/<id>/comments/', ...)
  - But included under: path('api/', include(...))
  - Result: /api/api/projects/<id>/comments/ (double prefix!)
  - Frontend calls: /api/projects/<id>/comments/ (mismatch!)

FILE MODIFIED:
--------------
auth_project/accounts/urls.py (Lines 125-128)

CHANGES:
--------
BEFORE:
  path('api/projects/<int:project_id>/comments/', get_comments, ...)
  path('api/projects/<int:project_id>/comments/add/', add_comment, ...)
  path('api/comments/<int:comment_id>/delete/', delete_comment, ...)
  path('api/comments/<int:comment_id>/edit/', edit_comment, ...)

AFTER:
  path('projects/<int:project_id>/comments/', get_comments, ...)
  path('projects/<int:project_id>/comments/add/', add_comment, ...)
  path('comments/<int:comment_id>/delete/', delete_comment, ...)
  path('comments/<int:comment_id>/edit/', edit_comment, ...)

WHY:
----
The 'api/' prefix is already added by:
  path('api/', include('accounts.urls'))

So specifying 'api/' again creates: /api/api/... (WRONG)
By removing it: /api/projects/... (CORRECT)
