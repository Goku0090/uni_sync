================================================================================
                           API ENDPOINTS
================================================================================

GET /accounts/api/projects/<project_id>/comments/
   - Fetch all comments for a project
   - Response: {success, count, comments[]}

POST /accounts/api/projects/<project_id>/comments/add/
   - Create new comment
   - Body: {content: "..."}
   - Response: {success, comment{}}

POST /accounts/api/comments/<comment_id>/edit/
   - Update comment text
   - Body: {content: "..."}
   - Response: {success, comment{}}

DELETE /accounts/api/comments/<comment_id>/delete/
   - Remove comment
   - Response: {success, message}

================================================================================
                        VALIDATION RULES
================================================================================

Comment Validation:
- Min length: 1 character (not empty)
- Max length: 1000 characters
- Required: User must be logged in to add

Permission Rules:
- View: Anyone can view (no auth required)
- Add: Logged-in users only
- Edit: Comment author only
- Delete: Author OR project owner

Error Handling:
- Empty comment: Shows "Comment cannot be empty"
- Too long: Shows "Comment is too long (max 1000 characters)"
- Permission denied: Shows "Permission denied" (403)
- Not found: Shows "Project not found" (404)

================================================================================
                        TROUBLESHOOTING
================================================================================

ISSUE: Comments not loading
FIX: Check browser console, verify CSRF token, check API response

ISSUE: Can't submit comment
FIX: Verify logged in, check comment length, clear cache

ISSUE: Edit/Delete buttons not visible
FIX: Verify you own comment, check permissions, refresh page

ISSUE: XSS still possible
FIX: All HTML escaped server-side, check escapeHtml() function

ISSUE: Comments count wrong
FIX: Hard refresh (Ctrl+Shift+R), check database count
