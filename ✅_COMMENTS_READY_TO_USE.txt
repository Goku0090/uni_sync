================================================================================
TROUBLESHOOTING
================================================================================

Issue: Comment section not showing
Solution: 
  1. Clear browser cache (Ctrl+Shift+Del)
  2. Refresh page
  3. Check F12 console for errors
  4. Verify template file exists

Issue: Comments not saving
Solution:
  1. Check Django logs in terminal
  2. Verify database connection
  3. Run: python manage.py migrate
  4. Restart server

Issue: "Method not allowed" error
Solution:
  1. Verify urls.py has API imports
  2. Check route patterns match
  3. Restart development server

Issue: Styling looks wrong
Solution:
  1. Clear browser cache
  2. Check if Bootstrap 5 is loaded
  3. Open F12 console for CSS errors
  4. Refresh page
