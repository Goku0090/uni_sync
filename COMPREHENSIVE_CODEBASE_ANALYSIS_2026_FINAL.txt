================================================================================
                      6. AUTHENTICATION SYSTEM
================================================================================

6.1 EMAIL OTP FLOW

User Registration/Login:
1. User enters email
2. System generates 6-digit OTP
3. Sends to email via Brevo/ZeptoMail API
4. User enters OTP
5. Validation & JWT token issued
6. Auto-login or prompt for profile

Code Path:
└── register_user() → OTP.generate_otp() → send_otp_email()
    └── verify_otp() → OTP.verify_otp() → login user

6.2 SOCIAL AUTHENTICATION (OAuth 2.0)

Google/GitHub Login:
1. User clicks "Login with Google/GitHub"
2. Redirects to provider
3. User authorizes
4. Provider redirects back with code
5. Backend exchanges code for token
6. Creates/retrieves user
7. Auto-login

Libraries:
├── django-allauth          - OAuth handling
├── SocialAccount model     - Provider credentials
└── SocialApp model         - App configuration

6.3 SESSION MANAGEMENT

├── Django Sessions (default)
├── JWT Tokens (for API)
├── CSRF Protection (middleware)
└── Secure Cookies (production)

Settings:
├── SESSION_COOKIE_SECURE = True
├── CSRF_COOKIE_SECURE = True
├── SECURE_SSL_REDIRECT = True
└── SameSite = 'Lax' / 'Strict'
