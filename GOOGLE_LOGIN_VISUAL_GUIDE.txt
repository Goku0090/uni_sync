COMMON MISTAKES TO AVOID:

❌ MISTAKE 1: Didn't click SAVE
   After adding URI, must click SAVE button
   Fix: Click SAVE, wait 30 seconds

❌ MISTAKE 2: Used different port
   Registered 8000, but running 8001
   Fix: Register the actual port you're using

❌ MISTAKE 3: Used 127.0.0.1 vs localhost
   They're different! Need both
   Fix: Register both versions

❌ MISTAKE 4: Typo in credentials
   Client ID or Secret copied wrong
   Fix: Copy directly from Google, not by hand

❌ MISTAKE 5: Didn't restart server
   Changed .env but didn't restart
   Fix: Ctrl+C, restart runserver
