✅ DJANGO TEMPLATE RECURSION ERROR - FIXED

PROBLEM:
========
Error: "maximum recursion depth exceeded"
Location: /accounts/project-detail/<id>/
File: auth_project/accounts/templates/includes/comment_section.html, line 2

ROOT CAUSE:
===========
Line 2 contained a Django template tag inside an HTML comment:
  <!-- Usage: {% include 'includes/comment_section.html' with project=project %} -->

Django's template engine parses ALL template tags before rendering, even inside HTML comments.
This caused the template to try to include itself, creating infinite recursion.

SOLUTION APPLIED:
=================
✓ Fixed line 2 of comment_section.html
  Changed FROM: <!-- Usage: {% include 'includes/comment_section.html' with project=project %} -->
  Changed TO:   <!-- include 'includes/comment_section.html' with project=project -->

Removed the Django template tag syntax ({% %}) from the comment so Django doesn't try to parse it.
