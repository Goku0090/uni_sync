================================================================================
                           TROUBLESHOOTING
================================================================================

Issue: Fields not auto-filling
Solution:
  1. Check browser console (F12)
  2. Test API: GET /api/templates/1/
  3. Check network tab
  4. Refresh page (Ctrl+F5)

Issue: Navbar looks wrong
Solution:
  1. Clear browser cache (Ctrl+Shift+Delete)
  2. Hard refresh page (Ctrl+Shift+R)
  3. Check CSS is loaded

Issue: TomSelect not updating
Solution:
  1. Verify TomSelect initialized
  2. Check field IDs match
  3. Open console for errors
