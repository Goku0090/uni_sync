# 🔐 Google Login - Start Here

## Your Error
```
Error: redirect_uri_mismatch
The redirect URI provided is not registered with the authorization server
```

## Why It Happens
Google doesn't recognize the callback URL your app is using.

## The Fix (5 minutes)

### 1️⃣ Find Your Callback URL
```
http://localhost:8000/accounts/google/login/callback/
```
(Or your actual domain if deployed)

### 2️⃣ Register in Google Cloud Console
1. Go to [console.cloud.google.com](https://console.cloud.google.com)
2. Select your project
3. **APIs & Services** → **Credentials**
4. Click your **OAuth 2.0 Client ID**
5. Scroll to **"Authorized redirect URIs"**
6. Click **"ADD URI"**
7. Paste: `http://localhost:8000/accounts/google/login/callback/`
8. Click **"SAVE"** (important!)

### 3️⃣ Update .env File
Make sure your `.env` has:
```bash
GOOGLE_CLIENT_ID=your_client_id_from_google.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_client_secret_from_google
ALLOWED_HOSTS=localhost,127.0.0.1
```

### 4️⃣ Restart Server
```bash
python manage.py runserver
```

### 5️⃣ Test
Visit: `http://localhost:8000/accounts/login/`

Click "**Login with Google**"

**Should work!** ✅

## Common Issues

| Problem | Solution |
|---------|----------|
| Still getting error | Did you click SAVE in Google Console? |
| Using `127.0.0.1` | Add both `localhost` and `127.0.0.1` to Google Console |
| Different port (8001) | Register with that port in Google Console |
| On production server | Use your domain URL in Google Console |
| Button not showing | Make sure django-allauth is installed and configured |
